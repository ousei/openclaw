# WDS完整技术架构与业务分析报告

## 公司概述
WDS是一家专注于智能硬件和物联网解决方案的公司，主要产品包括EG-Keeper系列智能终端设备、iFLINK物联网平台以及AIBOX边缘AI计算设备。

## 核心产品线分析

### 1. EG-Keeper系列（核心产品）
EG-Keeper是WDS的核心产品线，是一系列智能终端设备，具备人脸识别、门禁控制、体温检测等多种功能。

#### 产品型号分类：
- 基础版（EG-Keeper）
- SIM通信版（EG-Keeper SIM）
- 触摸屏版（EG-Keeper 8英寸）
- 网络安全版（EG-Keeper防火墙）
- 实时通信版（EG-Keeper_websocket）

#### 核心技术特性：
1. **人脸识别技术**
   - 人脸检测、识别、注册
   - 活体检测防伪
   - 人脸数据库管理（增删改查）
   - 黑白名单控制

2. **门禁控制系统**
   - 多种开门方式（刷卡、人脸、远程）
   - 权限组管理
   - 考勤记录追踪
   - 访客管理

3. **体温检测功能**
   - 红外测温
   - 环境温度补偿
   - 体温异常报警
   - 口罩识别

4. **网络通信能力**
   - DHCP/静态IP配置
   - HTTP/MQTT数据上传
   - WIFI连接管理
   - 端口配置

5. **多媒体支持**
   - 视频流传输（RTSP）
   - 图片数据处理（Base64编码）
   - 音频播放控制
   - UI界面定制

#### HTTP API接口体系：
根据API文档分析，EG-Keeper提供完整的RESTful API接口，主要包括：

1. **设备管理接口**
   - 获取/设置设备时间 (getTime/setTime)
   - 获取设备信息 (getDeviceInfo)
   - 网络参数配置 (setIpconfig)
   - 重启设备 (reboot)
   - 系统错误码查询

2. **人脸识别接口**
   - 人脸识别 (recognizeFace)
   - 人员名单管理（注册、查询、修改、删除）
   - 组名单管理（创建、查询、修改、删除）
   - 人脸数据管理（添加、删除）

3. **门禁控制接口**
   - 门禁开锁 (openlock)
   - 门禁参数配置
   - 权限组管理
   - 门禁事件上报

4. **体温检测接口**
   - 环境温度获取/设置 (getEnvTemp)
   - 体温数据上传
   - 测温参数配置

5. **数据上传接口**
   - HTTP上传配置 (getHttpCloud/setHttpCloud)
   - MQTT上传配置 (getMqtt/setMqtt)
   - 考勤记录查询 (queryAttendRecord)

6. **UI配置接口**
   - 面板机UI配置 (getUIConfig/setUIConfig)
   - 显示参数控制（语言、音量、亮度等）

### 2. iFLINK产品线
iFLINK专注于物联网设备连接和数据传输，主要面向工业控制场景。

### 3. AIBOX产品线
AIBOX是边缘AI计算设备，提供本地化的AI处理能力。

## 技术架构要点

### 硬件平台
- ARM架构处理器
- 支持多种传感器（摄像头、温度传感器、接近传感器等）
- 网络通信模块（以太网、WIFI、4G）

### 软件架构
- Linux操作系统
- 基于RESTful的HTTP API
- 支持MQTT协议的物联网通信
- 数据库管理系统（SQLite）
- 算法库（人脸识别、活体检测等）

### 开发语言和工具
- C/C++（底层驱动）
- Python（部分算法）
- JavaScript（Web界面）
- Shell脚本（系统配置）

## 版本演进历史
根据API文档中的版本更新记录，EG-Keeper的发展历程如下：

1. **初版 (V0.1, 2019-02-20)**：基础功能实现
2. **V0.2-V0.9 (2019年)**：增加了参数配置、人脸上传、错误码等核心功能
3. **V1.0.0 (2019-11-01)**：重大更新，增加RTSP、设备信息、网络配置、考勤记录等
4. **后续版本**：持续完善，增加了黑白名单、温度检测、门禁控制等高级功能

## 错误处理机制
完善的错误码体系覆盖各种异常情况：
- 系统级错误（重启、内存不足、存储空间不足）
- 应用级错误（参数无效、数据格式错误）
- 算法级错误（人脸检测失败、特征匹配失败）
- 网络级错误（连接失败、超时）

## 部署和维护
- 支持远程配置和固件升级
- 多种方式的数据上传（HTTP、MQTT）
- 完整的日志管理系统
- 灵活的UI定制能力
